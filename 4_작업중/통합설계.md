## 3. 통합 데이터 스키마 (핵심)

세 도메인을 하나의 JSON 배열로. 공통 필드 + 도메인별 선택 필드(`media`). **빌드리스**: 정적 `data/*.json`을 fetch.

```jsonc
{
  "id": "law-of-pragnanz",          // slug (URL·교차링크 키)
  "domain": "aesthetics",            // aesthetics | art-movement | creative-strategy
  "category": "perception",          // 도메인 내 분류
  "title": "프레그난츠의 법칙",
  "titleEn": "Law of Prägnanz",
  "origin": "막스 베르트하이머",      // 제안자/창시자
  "year": 1923,                      // 또는 period "1890–1910"
  "field": "게슈탈트 심리학",
  "oneLiner": "한 줄 정의",
  "desc": "심화 설명(2~3문단)",
  "rationale": "이론적 근거(미감의 why = 전략의 이론배경)",
  "apply": ["적용1", "적용2", "적용3"],
  "credibility": "established",       // ★신규 공통: established🟢|consensus🟡|disputed🟠|industry🔵|personal⚪
  "sources": [{"label":"Wertheimer 1923","url":"..."}],  // ★신규: 출처
  "related": ["proximity","similarity"],  // ★교차링크(도메인 횡단 가능)
  "keywords": ["단순성","질서","지각"],   // 검색·역색인
  "media": {                          // 도메인별 선택
    "svg": "<svg>...",                // 미감
    "palette": [{"hex":"#...","name":"..."}],  // 양식
    "fonts": [{"name":"...","css":"..."}],     // 양식
    "images": [{"src":"...","caption":"...","credit":"..."}]
  }
}
```

**설계 결정**
- `credibility`(신뢰도 배지) = 이 위키의 차별점. 미감·양식 항목엔 기본 🟢/🔵, 전략은 이론카탈로그 등급 적용.
- `related`는 데이터엔 항상 넣되(도메인 횡단: 예 "낙차"↔"스키마불일치"↔미감 "대비"), UI 노출은 우선순위상 후순위(2단계).
- 기존 미감 `why`→`rationale`, FORMA `traits/typo/figures`→`media`+`apply`로 매핑.

## 4. UX 규칙 (사용성 기준)

**기반 5원칙**(전 화면 공통 체크리스트)
1. **일관성** — 세 도메인이 같은 카드·상세 템플릿·인터랙션. 도메인 차이는 색 토큰 1개로만 구분.
2. **점진적 공개** — 랜딩=최소, 탐색=중간(카드), 상세=전체. 한 번에 하나만 연다(미감 아코디언 패턴 계승).
3. **인지부하 최소화** — 한 화면 1차 행동 1개. 필터·정렬은 접어두고 필요시 펼침.
4. **횡단 탐색** — `related`로 도메인 경계를 넘나듦(통합의 존재 이유). 상세 하단 "연결된 항목".
5. **접근성·반응형 기본** — 키보드 내비, ARIA, 명도대비 AA, 모바일에서 테이블→카드 전환, `prefers-reduced-motion`.

**사용자 우선순위 3종(집중 구현)**
- **① 첫인상·온보딩(랜딩)**: 한 문장 정체성 + 3도메인 카드 + "오늘의 항목" + 검색 진입. 3초 안에 "뭐 하는 곳"이 읽혀야.
- **② 전역 통합 검색**: 제목·영문·제안자·키워드·본문 대상 클라이언트 인덱스(JSON 역색인). 도메인 필터 토글. 미감엔 현재 검색 자체가 없으므로 체감 개선 최대.
- **③ 북마크·컬렉션**: localStorage 기반(서버리스). 별 토글 → "내 보드"에서 모아보기·컬렉션 분류·공유용 URL(상태 인코딩).

## 5. 화면 구성 (와이어 수준)

- **랜딩**: 히어로(정체성 한 줄) → 3도메인 진입 카드(미감/양식/전략, 항목 수 표시) → 오늘의 항목(셔플) → 전역 검색바 → 소개 링크.
- **통합 탐색**: 상단 검색바(고정) + 도메인 칩(전체/미감/양식/전략) + 카테고리 보조필터 + 정렬 + 카드 그리드. 카드=제목·영문·제안자·도메인색·신뢰도 배지.
- **상세**: 제목/영문/제안자·연도/도메인·카테고리/신뢰도 배지 → 한 줄 → 설명 → 이론적 근거 → 적용 → (미디어: SVG/팔레트/폰트/도판) → 출처 → 연결된 항목(related) → 북마크 토글.
- **내 보드**: 북마크 그리드 + 컬렉션 탭 + 비우기/공유.

1. 변환 스크립트(Node 일회성, _scratch): 미감 `data.js`(LAWS[]) → `data/aesthetics.json`, FORMA `data.js`(MOVEMENTS[])+`concepts-data.js` → `data/art-movement.json`. 필드 리네임 매핑 적용, `credibility` 일괄 부여.
2. 전략 `data/creative-strategy.json` 신규 작성(이론카탈로그 → 항목화, 8법칙 매핑 정정 반영).
3. 빌드 시 세 JSON을 fetch 병합 → 단일 인덱스. 이미지: 양식 갤러리 Pinterest 핫링크·미감 Wikimedia 핫링크는 **배포 전 라이선스 점검**(기존 미해결 과제 승계).

## 7. 로드맵 (제안)

- **P0 설계 확정**: 이 문서 + 스키마 + 사이트명·디자인 톤 합의. (현재 단계)
